STEP 1

Claude generates the presentation

HOW IT STARTS

User invokes /netlify-presentation-publisher
Skill SKILL.md is read — style tokens, structure rules
Claude generates a fully self-contained HTML file
Slides, transitions, navigation — all in one file

DESIGN SYSTEM

Font: Space Grotesk + Space Mono
Dark base: #0a0d14 background
Accents: Blue, Purple, Green, Orange
Keyboard nav + dot indicators + slide counter
STEP 2

GitHub MCP pushes the file

Claude uses the GitHub MCP connector — no manual git commands, no copy-paste.
# Claude calls create_or_update_file via GitHub MCP

}

# Then reads + updates presentations/index.html
STEP 3 → 4

Netlify deploys. URL goes live.

The GitHub repo Shrirampatki/Netlify is connected via continuous deployment. Every push to main triggers an automatic rebuild.
T+0s
Push received

GitHub MCP commits the HTML file to the Netlify repo on main.

T+5s
Netlify build triggered

Webhook fires; Netlify detects the new commit and starts deploying.

T+45s
Deploy complete

Static assets are live on the CDN edge network globally.

T+45s
Public URL accessible

Anyone with the link can open the presentation — no auth, no build tools.
