# Netlify Presentations

Auto-deployed HTML presentations generated by Claude.

## Live Site
https://shriram-ai-workspace.netlify.app

## How it works
1. Ask Claude: "Create a presentation on [topic]"
2. Claude generates the HTML and pushes it to presentations/
3. Claude updates index.html with a link to the new deck
4. Netlify auto-deploys in ~30 seconds

## Structure
presentations/
├── index.html                      ← menu page
├── skills-agents-docker.html       ← add new ones here
└── ...

## Setup
- GitHub → Netlify connection via: presentations/ folder
- Claude skill: "Netlify Presentation Publisher"
- Connectors needed: GitHub Integration
